# Guía de Plantillas Maestras: Objetos Relacionales y Procesos Universales

### Introducción al Patrón Contenedor-Elemento (S-A-M en Dos Etapas)

Esta guía establece el estándar para el diseño de clases en sistemas relacionales donde una clase mayor (procesadora/gerencial) gestiona múltiples instancias de una clase menor (procesada/pasiva), aplicando el **Procesamiento en Flujo** (sin uso de arreglos o listas en memoria).

Se basa en la regla mnemotécnica **C-A-M-P-P** para garantizar la cobertura de los cinco procesos universales de la informática de Nivel 1: Contar, Acumular, Mayor/Menor (con récord relativo), Promedio y Porcentaje.

---

### Etapa 1: Plantilla para la "Clase Menor" (Objeto Procesado / Pasivo)

**Responsabilidad:** Representar una transacción o registro individual. Encapsula los datos estáticos de entrada y realiza cálculos internos puros que *solo dependan de sus propios atributos*.

**Archivo:** `[[NombreDelElemento]].js`

export default class [[NombreDelElemento]] {
  // -------------------------------------------------------------------------
  // 1. ATRIBUTOS PRIVADOS (Encapsulamiento)
  // Generalmente un identificador (string) y los valores numéricos de entrada.
  // -------------------------------------------------------------------------
  [[Atributos_Encapsulados]] // Ej: private _id: string; private _valorEntrada: number;

  // -------------------------------------------------------------------------
  // 2. CONSTRUCTOR
  // Recibe los valores iniciales y usa los setters para asignarlos.
  // -------------------------------------------------------------------------
  constructor([[Parametros_Constructor]]) {
    [[Asignaciones_Iniciales_Usando_Setters]]
    // Ej: this.id = id; this.valorEntrada = valorEntrada;
  }

  // -------------------------------------------------------------------------
  // 3. SETTERS Y GETTERS (Encapsulamiento Garantizado)
  // Un set y un get por cada atributo. El setter debe asegurar la conversión de tipo.
  // -------------------------------------------------------------------------
  [[Bloque_Setters_y_Getters]]
  /* Ejemplo:
  set valorEntrada(v: number) { this._valorEntrada = +v; }
  get valorEntrada(): number { return this._valorEntrada; }
  */

}

### Etapa 2: Plantilla para la "Clase Mayor" (Objeto Procesador / Activo)

**Responsabilidad:** Procesar múltiples instancias de la clase menor en tiempo real cruzando la "puerta" de entrada. Almacena las variables acumulativas del negocio (C-A-M-P-P) e implementa los métodos de reporte gerencial.

**Archivo:** `[[NombreDelContenedor]].js`

```typescript
// ARCHIVO: [[NombreDelContenedor]].js
// DEPENDENCIA: Requiere importar la clase menor.
import [[NombreDelElemento]] from './[[NombreDelElemento]].js';

export default class [[NombreDelContenedor]] {
  // -------------------------------------------------------------------------
  // 1. ATRIBUTOS DE PROCESAMIENTO (Variables de Control C-A-M-P-P)
  // Son privados. Guardan el estado acumulativo del negocio.
  // -------------------------------------------------------------------------
  
  // A - Acumular (¿Cuánto en total?): Sumatorias de valores variables.
  [[Atributos_Acumuladores]] // Ej: private acTotal: number;

  // C - Contar (¿Cuántos?): Cuenta ocurrencias constantes (+1).
  [[Atributos_Contadores]] // Ej: private cntItems: number;

  // M - Mayor/Menor (El Récord - VARIANTE RELATIVA):
  // Guarda el valor récord Y el identificador asociado a ese récord.
  [[Atributos_Records_Valor]]      // Ej: private valRecord: number;
  [[Atributos_Records_Relativos]]  // Ej: private idRecord: string;

  // P/P - Componentes de Fórmulas Compuestas (Promedio y Porcentaje):
  // (Requiere acumuladores y contadores adicionales según la fórmula).
  [[Atributos_Fórmulas]] // Ej: private cntCondicionEspecial: number;

  // -------------------------------------------------------------------------
  // 2. CONSTRUCTOR
  // Inicializa OBLIGATORIAMENTE todos los atributos de procesamiento en CERO (0) o vacío ('').
  // -------------------------------------------------------------------------
  constructor() {
    [[Inicializacion_C_A_M_P_P]]
    // Ej: this.acTotal = 0; this.cntItems = 0; this.valRecord = 0; this.idRecord = '';
  }

  // -------------------------------------------------------------------------
  // 3. MÉTODO NÚCLEO: EL PROCESADOR RECEPTOR (procesarXXX)
  // Recibe UNA instancia de la clase menor y actualiza la lógica global.
  // Es el gatillo de los procesos universales.
  // -------------------------------------------------------------------------
  procesar[[NombreDelElemento]]([[Identificador_Elemento]]: [[NombreDelElemento]]): void {
    
    // --- LÓGICA DE ACUMULACIÓN (A - ¿Cuánto en total?) ---
    // Actualiza acumuladores con valores directos o calculados de la clase menor.
    [[Logica_Acumuladores]] // Ej: this.acTotal += [[Identificador_Elemento]].[[Dato_o_Calculo]];

    // --- LÓGICA DE CONTEO GENERAL (C - ¿Cuántos?) ---
    // Incrementa el contador principal.
    [[Logica_Contador_General]] // Ej: this.cntItems++;

    // --- LÓGICA DE MAYOR/MENOR RELATIVO (M - El Récord) ---
    // Compara el valor actual contra el récord y actualiza AMBOS atributos si se supera.
    /* Ejemplo:
    if ([[Identificador_Elemento]].[[Dato_o_Calculo]] > this.valRecord) {
      this.valRecord = [[Identificador_Elemento]].[[Dato_o_Calculo]];
      this.idRecord = [[Identificador_Elemento]].[[Identificador]];
    }
    */
    [[Logica_Max_Min_Relativo]]

    // --- LÓGICA DE CONTEO ESPECÍFICO (Para Porcentajes) ---
    // Incrementa contadores de una "parte" basado en una condición.
    [[Logica_Contador_Condicional]] // Ej: if ([[Identificador_Elemento]].esValido()) this.cntCondicionEspecial++;
  }

  // -------------------------------------------------------------------------
  // 4. MÉTODOS DE REPORTE (Salida Gerencial)
  // Métodos públicos que retornan los resultados consolidados finales.
  // -------------------------------------------------------------------------

  // Reportes de Acumulación/Conteo Directos
  [[Metodos_Reporte_Directo]] // Ej: return this.acTotal; return this.cntItems;

  // M - Reporte de Récord Relativo
  // Retorna el identificador asociado al valor récord.
  [[Metodo_Reporte_Record_Relativo]] // Ej: return this.idRecord;

  // P - Promedio (Reparto en partes iguales)
  // Fórmula: Acumulador / Contador (IMPORTANTE: Validar división por cero).
  promedio[[NombreDelCalculo]](): number {
    if (this.[[Contador_Divisor]] === 0) return 0;
    return this.[[Acumulador_Dividendo]] / this.[[Contador_Divisor]];
  }

  // P - Porcentaje (Porción)
  // Fórmula: (Contador Parte / Contador Total) * 100 (IMPORTANTE: Validar división por cero).
  porcentaje[[NombreDelCalculo]](): number {
    if (this.[[Contador_Total_Divisor]] === 0) return 0;
    return (this.[[Contador_Parte_Dividendo]] / this.[[Contador_Total_Divisor]]) * 100;
  }
}

```

### Tabla de Equivalencias: Plantilla vs. Procesos Universales (C-A-M-P-P)

| Proceso Universal | Rol en la Plantilla Maestra (Clase Mayor) | Gatillo (¿Dónde se ejecuta?) |
| --- | --- | --- |
| **C - Contar** | Atributo Contador y `cnt++`. | `procesarXXX()` (lógica directa). |
| **A - Acumular** | Atributo Acumulador y `acum += valor`. | `procesarXXX()` (lógica directa). |
| **M - Mayor/Menor (Relativo)** | Atributos de Récord (Valor e ID), y bloque `if (actual > record)`. | `procesarXXX()` (lógica condicional). |
| **P - Promedio** | Métodos de Reporte (retornan Acum/Cont). | Método de Reporte (al consultar). |
| **P - Porcentaje** | Métodos de Reporte (retornan (Parte/Total)*100). | Método de Reporte (al consultar). |
